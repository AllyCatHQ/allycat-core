Contrast CSS Test

Tests contrast detection across inline, external, and embedded CSS styles.

Section 1 — Inline Styles

These use style="" directly on the element.

Inline: light gray on white (~1.6:1) — SHOULD FAIL AA

Inline: yellow on white (~1.07:1) — SHOULD FAIL AA

Inline: gray on gray (~2.3:1) — SHOULD FAIL AA

Inline: black on white (21:1) — SHOULD PASS

Inline: navy on white (~14.7:1) — SHOULD PASS

Section 2 — External CSS (contrast-external.css)

These use classes from an external stylesheet.

External: .ext-fail-light-gray (~1.6:1) — SHOULD FAIL AA

External: .ext-fail-yellow (~1.07:1) — SHOULD FAIL AA

External: .ext-fail-gray-on-gray (~2.3:1) — SHOULD FAIL AA

External: .ext-fail-borderline (~4.48:1) — SHOULD FAIL AA

External: .ext-pass-black (21:1) — SHOULD PASS

External: .ext-pass-navy (~14.7:1) — SHOULD PASS

External: .ext-pass-aa-only (~5.9:1) — PASSES AA, FAILS AAA

Section 3 — Embedded Style Block

These use classes from the <style> block in <head>.

Embedded: .emb-fail-red-on-pink (~2.1:1) — SHOULD FAIL AA

Embedded: .emb-fail-white-on-lt (~1.1:1) — SHOULD FAIL AA

Embedded: .emb-pass-black (21:1) — SHOULD PASS

Embedded: .emb-pass-dark-blue (~8.6:1) — SHOULD PASS
